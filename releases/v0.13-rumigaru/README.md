# Radio Roam v0.13 — ルミガルの個別パーツ（作業版）

ESP32-S3の丸型タッチ液晶を使ったポケット育成ゲームです。Lo-Viのハードウェアを流用し、コードベースは独立しています。

Wi-Fi環境からのイベント生成、育成、コマンド戦闘、スキャン捕獲、合成、Androidブラウザ連携、画面スリープを含む既存実装に、新しい魚型パーツを追加しています。

## この版の変更

- ルミガルの頭・胴体・胸ビレ・発光アンテナを、それぞれ独立した画像として追加。
- パーツの遺伝子によって新しい画像を選択。頭は第2候補、胴体は第4候補、胸ビレとアンテナは第1候補に対応します。
- 魚型用に3配色を追加し、スマホ側の画像キャッシュ識別子も更新。
- 原画はプロジェクト直下の `art/original-monsters-20260926/parts-source/`、変換処理は `tools/compile_rumigaru.py`。

## 状態

2026-10-05時点の作業版です。この版の実機転送・通常起動確認は未完了です。バルクルの参考画像はありますが、追加パーツは未実装です。最後に確認済みの実機版はv0.11です。

既存キャラの遺伝子やセーブ形式を変更しません。端末バックアップ・個人のセーブデータ・認証情報は配布対象に含めません。

## ローカル確認

プロジェクト直下で実行します。

```sh
python -m unittest discover -s releases/v0.13-rumigaru/tests
```

画像を再変換する場合はPillowが必要です。

```sh
python tools/compile_rumigaru.py
```

実機への転送対象はこのフォルダー内の `firmware/` です。プロジェクト直下の古い `firmware/` と混同しないでください。転送前に端末のセーブをバックアップし、機種・接続ポートを確認してください。
